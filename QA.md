# QA-матрица Stepwise

Чек-лист перед показом. Отмечено то, что реально проверено, и указано чем —
автоматической проверкой или руками.

## Как прогнать автоматическое

```bash
npm run typecheck        # типы
npx vitest run           # весь набор тестов
npx eslint               # линт
npm run build            # продакшен-сборка

# мобильная проверка в настоящем браузере
npm run build
npx next start -p 3123
node scripts/mobile-qa.mjs   # 360 / 390 / 430 px, скриншоты в public/qa
```

`scripts/mobile-qa.mjs` падает, если на экране появилось горизонтальное
переполнение или кнопка ниже 32px, и отдельно — если экран вообще не
отрисовался. Последнее важно: проверка, которая измеряет страницу ошибки
браузера, хуже отсутствующей.

## Пять состояний экрана

| Состояние | Где живёт | Проверено |
|---|---|---|
| loading | `LoadingState` — скелетоны, никогда не «0 путей» | ✅ |
| empty | `EmptyState` — всегда с действием | ✅ |
| error | `app/(app)/error.tsx` + `ErrorState` | ✅ |
| no-data | `NoDataNote` + статус `needs_data` | ✅ |
| offline | `OfflineBanner` | ✅ |

`no-data` и `error` намеренно разные: первое — «данных не хватает, чтобы
посчитать честно», второе — «что-то сломалось».

## Что проверено вручную

- Полный путь: лендинг → `/start` → вопросы → `/diagnostics` → `/doors` →
  детали → `/compare` → `/roadmap` → `/next-action`.
- Правка бюджета с доски: пересчёт мгновенный, оверлей «Что изменилось»
  открывается, доска меняется.
- Скриншоты всех экранов на 360/390/430 лежат в `public/qa/`.

## Профили

- Вход по имени и фамилии, возврат к своему профилю, переключение и демо в
  отдельной коробке — покрыто `tests/profiles.test.ts`, включая исходный баг:
  «посмотреть на демо» больше не стирает чужие ответы.
- Прогон в браузере: `/start` → имя → интервью → доска → демо → возврат.
  Коробки `stepwise-storage:demo` и `stepwise-storage:p1` держат разные профили.

## Известные ограничения

- Каталог настоящий: 75 вузов, 85 источников, 10 шагов. Уровень доверия у
  каждой даты свой — 23 подтверждены целиком, у 38 год выведен по циклу
  поступления, 8 взяты из прошлого цикла, 6 остались без даты. Экран говорит
  это о себе; см. «Данные и источники» в README.
- Живого вызова провайдера на этой машине не было: ключа нет. Продукт работает
  полностью без него, объяснения детерминированные.
- В дереве остались экраны первого поколения (`features/doors`, `features/roadmap`,
  `features/compare`, `features/diagnosis`, `features/profile`, `features/changes`,
  `engine/`) — маршруты на них больше не ведут.
